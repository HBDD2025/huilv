# Cards Magic by CZH

发布仓库为 `HBDD2025/huilv`，本项目单独放在 `cards/`。固定入口为该 GitHub Pages 站点的 `/huilv/cards/`。PayGlobe 根目录不属于本项目的修改范围。

## 日常使用

首页输入餐饮、电费、水费、超市、机票、卡名等关键词。餐饮等按明确的类别倍率比较；生活缴费没有已核验专项加倍时按普通消费列卡。钱包支付默认不假设商户分类必然传递。Atmos 境外加倍与 BofA 关系加成可按已知账户条件单独勾选。

美国卡查询后直接列出全部 11 张卡。Trip.com、携程、Expedia 等第三方旅行平台仅作场景识别，默认按普通消费保守估算；账单确认旅行／旅行社类别后才计入适用类别加成，且不会误用品牌直订或银行自家门户倍率。回报百分比为“倍率 × 自定每点美分价值”，再减通道手续费；是旅行兑换规划估值，不是保证现金返点。Savor 的现金回馈单独标明。点值范围可修改、保存在当前浏览器。不同设备不自动同步。未知用途不会伪装成命中。

手机首页、美国卡与香港卡均为纵向卡片；大范围对比、原始规则表可在各自容器内横向滚动。初次实测使用 390px 宽 iframe 手机视窗（内容区 375px），不代表所有手机和浏览器均已真机测试。

## 文件

- `data/cards.json`：11 张美国卡的权益、活动、来源及点值假设。
- `data/hk-cards.json`：23 张香港卡与扣账卡的简要用途、回赠条件、官方链接；卡种不明确的项目不推测回报。
- `web/hk.js`：香港卡按银行、类型、用途及商户模糊检索。
- `web/template.html`：页面模板。
- `web/recommend.js`：关键词、类别、地区、渠道、封顶及回报计算。
- `web/advisor.js`：场景查询界面和本机点值设置。
- `scripts/build.py`：生成可直接打开的 `index.html`，无需 npm 依赖。
- `scripts/check_sources.py`：官方网页指纹巡检，不自动编造新权益。
- `scripts/test_recommend.cjs`：水电费、地区、钱包、封顶、费用与现金回馈的计算检查。

从本目录运行：

```bash
python3 scripts/validate.py
node scripts/test_recommend.cjs
python3 scripts/build.py
```

所有编辑以源文件为准，同时上传生成的 `index.html`。不要运行首版 `seed.py` 或 `redesign.py` 重置后续修改的数据。

## 发布及维护

用户已要求：在本专题发送相关新信息后，核验并压缩为简要结论，每次更新都上传到固定 GitHub 入口。使用 GitHub 文件或 Git Tree 接口更新 `cards/` 内的数据和页面；不要只提供下载文件就声称上线。

GitHub 每日官方来源巡检包含美国来源及香港卡产品链接；抓取失败仅记录状态，不代表权益失效。工作流位于仓库根目录 `.github/workflows/update-cards.yml`；网页变化只标记待复核，不直接替换已核验权益。抓取失败保留既有正确数据。原计划每周创建 ChatGPT 语义归纳任务，但本次创建因账号已有 5 个定时任务达到上限被拒绝，尚未启用。后续需用户腾出任务名额才能创建；不要声称已经运行。调度可延迟，实际状态看工作流及任务记录。

页面目前由公开 GitHub Pages 托管，任何人可见产品清单。公开文件不含卡号、额度、批卡日期或账户通知原图；个人备注和已使用额度只保存在浏览器。不要将本机备份提交到仓库。
